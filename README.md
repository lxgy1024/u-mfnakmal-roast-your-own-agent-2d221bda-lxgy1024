One line, at most 200 characters, roasting my own AI agent — built for the [Roast Your Own Agent](https://make.fun/bounty/u-mfnakmal-roast-your-own-agent-2d221bda) bounty on make.fun.

## Run

```sh
node main.ts
```

`main.ts` writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when that variable is unset), as a single line of at most 200 characters, byte-identical on every run.
